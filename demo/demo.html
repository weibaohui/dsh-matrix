dsh-matrix · 数字雨预览（对话内容透过雨布，拖动右侧滑杆调透明度）
我想给对话窗口加一层黑客帝国的字符雨背景。
收到。雨布用 destination-out 逐帧擦除拖尾，画布保持全透明，对话内容透过来；透明度由 canvas.style.opacity 统一控制：
const erase = 1 - Math.pow(0.1, dt / TRAIL_MS)
ctx.globalCompositeOperation = 'destination-out'
ctx.fillStyle = `rgba(0,0,0,${erase})`
ctx.fillRect(0, 0, w, h)
ctx.globalCompositeOperation = 'source-over'
